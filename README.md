# Bracket Bastion

Tax-themed tower defense — build towers, clear waves, protect your gate.

## Develop

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy (GitHub Pages)

Pushes to `main` run [`.github/workflows/pages.yml`](.github/workflows/pages.yml): build with the correct `base` path, then publish `dist/`.

After the first deploy, enable **Settings → Pages → Source: GitHub Actions** if prompted.

Live URL: `https://coderscamp-nation.github.io/BracketBastion/`
